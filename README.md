# Фінальний проєкт з реляційних баз даних

**Герасимюк Юлія**

## Опис проєкту

У цьому проєкті я працювала з датасетом `infectious_cases`, який містить дані про інфекційні захворювання в різних країнах, територіях і регіонах за роками.

Для виконання завдань використовувала PostgreSQL, Python та Google Colab.

## Що я зробила

1. Створила схему `pandemic` та завантажила CSV-файл із 10 521 записом.
2. Нормалізувала дані до третьої нормальної форми (3НФ), розділивши їх на таблиці `entities` та `infectious_cases_normalized`.
3. За допомогою `GROUP BY`, `AVG`, `MIN`, `MAX` і `SUM` проаналізувала дані про захворюваність на сказ.
4. Використала `MAKE_DATE`, `CURRENT_DATE`, `AGE` та `EXTRACT` для роботи з датами.
5. Створила дві SQL-функції: для розрахунку різниці в роках та середньої кількості випадків захворювання за різні періоди.
6. Перевірила результати нормалізації та зв'язки між таблицями.

## Результати

Після нормалізації отримала 245 унікальних пар `Entity` і `Code`. У таблиці захворювань залишилося 10 521 запис, усі зв'язки між таблицями працюють правильно.

## Як запустити проєкт

1. Відкрити файл `goit_rdb_fp_Herasymiuk_Yuliia.ipynb` у Google Colab.
2. У меню Runtime → Change runtime type вибрати:
   - Runtime type: Python 3
   - Hardware accelerator: CPU
3. Запустити всі комірки через Runtime → Run all.
4. Дочекатися встановлення бібліотек і запуску PostgreSQL.
5. CSV-файл автоматично завантажиться з Google Drive.
6. Переглянути результати SQL-запитів і перевірок у ноутбуці.
